 Student Performance Prediction
Project Overview

Student Performance Prediction is an AI and Machine Learning-based web application developed using Python and Django. The system predicts a student's expected final score based on important academic and behavioral factors.

The application allows users to register and log in, view student performance through an interactive dashboard, enter academic details, and obtain a predicted final score using a trained Machine Learning model.

The main goal of this project is to demonstrate how Machine Learning can be integrated with a Django web application to support student performance analysis and prediction.

 Objectives
Predict the expected final score of a student using Machine Learning.
Analyze factors that influence student academic performance.
Provide an easy-to-use web interface for entering student information.
Visualize student performance using charts.
Integrate a trained ML model with a Django application.
Provide a centralized dashboard for student performance analysis.

Prediction Features

The Machine Learning model uses student-related academic information to predict the final score.

The prediction form contains:

Feature	Description
Student ID	Unique identifier for the student
Attendance (%)	Student attendance percentage
Internal Test 1	Marks obtained in Internal Test 1
Internal Test 2	Marks obtained in Internal Test 2
Assignments Score	Student assignment performance
Daily Study Hours	Average number of hours studied per day
Previous Semester Marks	Previous semester academic performance
Example Input
Student ID             : 1000
Attendance              : 78%
Internal Test 1         : 67
Internal Test 2         : 34
Assignments Score       : 56
Daily Study Hours       : 12
Previous Semester Marks : 78
Example Prediction
Predicted Final Score: 54.66

The predicted score is an estimated result generated by the Machine Learning model and should not be considered an official academic result.

⚙️ Installation and Setup
1. Clone the repository
git clone https://github.com/YOUR-USERNAME/student-performance-prediction.git
2. Navigate to the project
cd student-performance-prediction
3. Create a virtual environment
python -m venv venv
4. Activate the virtual environment

For Windows PowerShell:

.\venv\Scripts\Activate.ps1

For Windows Command Prompt:

venv\Scripts\activate
5. Install dependencies
pip install -r requirements.txt
6. Apply Django migrations
python manage.py migrate
7. Start the development server
python manage.py runserver
8. Open the application

Open:

http://127.0.0.1:8000/
🔒 Security and Privacy

The following files should not be committed to a public repository:

venv/
__pycache__/
*.pyc
db.sqlite3
.env

API keys, passwords, secret keys, and private student information should never be published in the repository.

The dataset should contain only non-sensitive or anonymized information.
